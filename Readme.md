# Fan Control Application

A Node.js/Bun application to control fans under heaters with a RESTful API.

## Features

- CRUD operations for fan management
- Fan control (toggle on/off, speed control)
- Temperature monitoring
- HTTPS support
- PostgreSQL database with Drizzle ORM
- Docker Compose setup for easy deployment

## Requirements

- [Bun](https://bun.sh/) >= 1.0
- [Docker](https://www.docker.com/) and Docker Compose
- [Node.js](https://nodejs.org/) >= 18 (optional, as Bun includes Node.js
